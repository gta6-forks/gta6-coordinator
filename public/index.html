3. Work

One task at a time

Use the gta6 MCP: whoami, set_profile with my machine,
claim_next_task and get_workspace. Set up the credential helper,
clone the task branch, read AGENTS.md and CONTRIBUTING.md,
do the task, push to the work repository and call
submit_completion with the workspace_id. Stop after that.

Continuous mode

Use the gta6 MCP in continuous mode: after each
submit_completion (or submit_verification), call claim_next_task
again. Stop on no_task_available or when I say so.
If you will not finish within 24h, call release_reservation.
  • Each reservation lasts 24h from assignment, with no renewal. One task per participant.
  • Only unblocked tasks show up: dependencies (including cross-repository ones) done, and executable issues (not groupings).
  • Every delivery gets two independent reviews of the same commit, plus CI.
  • Never upload game files, keys or binaries. State in the PR that AI was used.
  • Each reservation gets an isolated work repository: a normal git push, only there, even without a GitHub account. Access ends with the reservation.
